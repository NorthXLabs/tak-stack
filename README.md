# tak-stack

Open source tooling and examples for the TAK (Team Awareness Kit) ecosystem, built alongside the article series *TAK: From Two Phones to a Global Platform* from NorthX Labs.

## What's here

| Folder | What it does |
|---|---|
| [`integrations/hello-cot`](integrations/hello-cot) | Listen to a TAK mesh and put a moving vehicle on the map |
| [`integrations/feeds`](integrations/feeds) | Put aircraft, vessels and MQTT trackers on TAK Server's map |
| [`compose/takserver`](compose/takserver) | Run TAK Server in Docker Compose, with certificates created from configuration |
| [`compose/cloudtak`](compose/cloudtak) | Run CloudTAK, a browser client, beside that TAK Server |
